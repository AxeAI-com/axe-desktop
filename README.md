# Axe AI desktop

Your agents, on your computer.

Axe AI desktop is one chat for Axe models, Claude Code, Codex, Gemini CLI and local models. It can use your
computer, run its own browser, search your files and run agents on boards. It asks before it pays, sends or
deletes anything. One codebase for Mac, Windows and Linux.

Download it at [axeai.com/download](https://axeai.com/download).

## Build it

You need Node 24 or newer and pnpm 10.

```bash
cd next
pnpm install --frozen-lockfile
scripts/check
```

`next/BUILD.md` covers the layout, the design rules and how each feature works.
